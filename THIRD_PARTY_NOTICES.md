# Dependency and runtime notices

This source-only draft bundles no third-party library, native binary, certificate, signing key, external game content, or installed environment package. The selected JavaScript/TypeScript files name `esbuild`, `postcss`, `tailwindcss`, and `typescript` as external package imports. `build-private-clock.mjs` also reads a separately installed `zod` package and its license when constructing a private evaluation archive. The scripts refer to other private-platform modules, build inputs, a native compiler, Electron runtime files, local test profiles, and Windows process behavior. Review those inputs and their license terms before attempting any integration. Source availability alone does not authorize connector pairing, an installed-clock operation, an updater action, or use of a private tunnel.
